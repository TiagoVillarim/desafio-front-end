Olá tudo bem ? este é o meu desafio para o processo seletivo da Allintra, abaixo estarei informando quais os passos para rodar o projeto localmente

-Primeiro instalei a Biblioteca Docusaurus utilizando o seguinte comando "npx create-docusaurus@latest my-website classic --typescript";
-Após instalar a lib realizei a instalação dos pacotes NPM com o seguinte comando "npm install";
-Por fim para poder rodar o projeto localmente basta abrir o terminal e rodar o compando "npm start" que o projeto irá ser aberto no browser

Libs utilizadas no projeto:
  - Docusaurus
  - Axios
  - Material-ui
  - Styled-components
  - react-markdown
